# ENACT 연구참여자 체험용 웹앱 (홈 화면 + 영상 지원)

## 홈 화면
통증 기록 → 걷기 → 마음챙김 → 통증 교육 → NERO 챗봇 순서로 5개 메뉴가 한 화면에 표시됩니다. 각 메뉴는 클릭하여 체험할 수 있으며 완료 여부가 표시됩니다.

## 영상 연결 (영상 연결 완료)
마음챙김: `videos/mindfulness.mp4`가 포함되어 있습니다. 필요 시 교체할 수 있습니다. MP4는 영상 재생이 끝나야 완료 버튼이 활성화됩니다.
통증 교육: `PNE_YOUTUBE_URL`에 https://www.youtube.com/watch?v=-wG5tnUic6Q 가 설정되어 있습니다. YouTube는 시청 완료 여부를 자동 검증하지 못하므로 참여자가 시청 후 완료 버튼을 누릅니다.
두 방법 중 하나만 사용하면 됩니다. YouTube 주소가 있으면 우선 적용됩니다. YouTube 영상의 임베드 허용 여부도 확인하세요.

## 설문지 연결
`index.html`의 `SURVEY_URL`에 Google Forms 주소를 입력하세요.

## 배포
GitHub 저장소 최상위에 `index.html`, `server.js`, `package.json`, `README.md`, `videos` 폴더를 올리고 Railway에서 GitHub Repository로 배포하세요. Railway 공개 도메인을 생성하세요.

## 주의
- NERO 3개 질문/답변은 제공된 화면 내용을 반영했습니다. 문헌표시와 연구팀 카카오톡 링크를 배포 전 검증하세요.
- 마음챙김 MP4 영상은 videos/mindfulness.mp4에 포함되어 있습니다. 통증 교육 영상은 YouTube 임베드로 연결되어 있으며 영상 제공자의 임베드 설정에 따라 재생이 제한될 수 있습니다.
- 서버는 통증 점수나 챗봇 사용 정보를 수집하지 않습니다. 접속 로그는 별도로 발생할 수 있습니다.
- 실제 GPS/거리 측정 없이 걷기 타이머만 시연합니다.
- 연구참여자 배포 전 IRB 승인 내용과 영상 저작권 및 임상정보의 적절성을 확인하세요.
