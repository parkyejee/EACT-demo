# ENACT 연구용 체험 웹앱 UI/UX 개선본

기존 Railway 서비스의 GitHub 저장소 파일을 교체하여 배포하세요. 기존 Railway URL은 유지됩니다.

- 홈: 다섯 가지 체험 메뉴 및 진행률
- 통증: 0~10점 기록, 기록 완료 화면, 최근 7일 그래프
- NERO: 실제 답변을 포함한 사전 정의 질문 3개 선택
- 걷기: 시연용 타이머 (GPS 미사용)
- 마음챙김: videos/mindfulness.mp4 재생 완료 후 확인
- 배우기: YouTube PNE 영상 임베드
- 기록: 달력, 수행 로그, 통증 추이. 과거 데이터는 표시하지 않으며 체험 입력만 반영

Google Forms URL은 index.html 내 SURVEY_URL에 입력하세요. YouTube 임베드 가능 여부, 카카오톡 링크, 의료 정보와 문헌 번호를 연구팀에서 확인하세요.

주의: 실제 앱 UI/UX를 참고한 재현이며 실제 앱의 모든 데이터/기능과 완전히 동일하지 않습니다. 연구 참여자에게 배포 전 모바일 기기에서 전체 흐름을 검증하고 IRB 승인 범위와 일치하는지 확인하세요.
